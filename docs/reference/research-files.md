# Research files: what each one holds and where it is used

All inputs of the map live in [`research/2026-10/`](../../research/2026-10/README.md): JSON files with the numbers (each value with low, central and high, a certainty letter and sources) and, next to almost every JSON file, a `*-notes.md` file with the method, the sources with retrieval dates, and the reasoning behind each educated guess. This page lists every file, what it contains, which build step reads it and which documentation page explains it. Paths like `working/...` in older notes refer to research scripts and raw downloads that are not published; since round 13, new scripts are in [`research/2026-10/scripts/`](../../research/2026-10/scripts/) (with the round-6 value-kept scripts), and raw OECD STAN, OECD TiVA and UN Comtrade HS 2710 downloads in `raw/`. None of the research files has been reviewed line by line by a person yet.
